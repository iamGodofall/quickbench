# Quickbench Commercial Path

Quickbench is the evaluation and regression-testing component of the ABSuite ecosystem.

## Open-source role

Quickbench should make reproducible local evaluation easy enough that developers use it before they need an enterprise evaluation platform.

## Commercial opportunities

Potential paid layers include:

- hosted evaluation runs
- private evaluation infrastructure
- enterprise regression dashboards
- evaluation dataset management
- scheduled benchmark pipelines
- deployment qualification
- custom evaluation suites
- integration services

## Adoption funnel

```
local benchmark
   ↓
repeatable regression workflow
   ↓
team benchmark suite
   ↓
CI / production evaluation
   ↓
managed enterprise evaluation
```

## What to measure

- weekly package downloads
- evaluation runs
- active projects
- CI integrations
- benchmark suites created
- organizations using it
- paid pilots
- recurring revenue

The goal is not to sell a dashboard before the underlying evaluation workflow is valuable. Build the measurement primitive first.
